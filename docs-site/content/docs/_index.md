Welcome to the AI-Assisted DevSecOps Workflows documentation. This guide is organized into focused sections that cover the full spectrum of integrating LLM assistants into security-first development and operations.

## Start Here

New to AI-assisted DevSecOps? We recommend reading in this order:

1. **[Architecture](architecture)** — Understand the agent pantheon, system design patterns, and how specialized AI agents map to DevSecOps responsibilities.
2. **[Security](security)** — Review the threat model, critical controls, and hardening guides before deploying AI assistants in production.
3. **[Paradigms](paradigms)** — Learn the three primary approaches (Multi-Agent, Pair Programming, CLI) and when to use each.
4. **[Frameworks](frameworks)** — Compare oh-my-opencode-slim, Aider, ShellGPT, AIChat, Claude Code, and Crush.

## Quick Reference

- **Agent Pantheon**: Orchestrator, Explorer, Librarian, Observer, Oracle, Fixer, Designer, Council
- **Core Principle**: Security-first — verify before execute, least privilege, audit trail
- **Primary Tools**: oh-my-opencode-slim, opencode-go/crush, Aider, ShellGPT, AIChat
